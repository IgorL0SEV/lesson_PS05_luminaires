# Парсер источников освещения с сайта Divan.ru

Этот проект представляет собой Scrapy-паука, предназначенного для сбора данных об осветительных приборах с сайта Divan.ru. 
Паук извлекает название товара, его цену и ссылку на страницу продукта.

Функциональность
Сбор данных: Скрипт автоматически переходит на страницу категории освещения на сайте Divan.ru и извлекает информацию о каждом товаре.​
